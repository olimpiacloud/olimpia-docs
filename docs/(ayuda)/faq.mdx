<Accordion>
  <AccordionItem title="¿Dónde corre Olimpia?">
    En Buenos Aires. Tus apps, bases e instancias de Redis corren en la región BUE; el tráfico web entra por [Olimpia CDN](/cdn). Ver [Región BUE](/plataforma/buenos-aires).
  </AccordionItem>
  <AccordionItem title="¿Tengo que cambiar mi código?">
    No. Postgres y Redis son los de siempre y los buckets hablan la API de S3: tus drivers, ORMs y SDKs funcionan igual. Lo único que necesita tu app es escuchar en `0.0.0.0:$PORT`.
  </AccordionItem>
  <AccordionItem title="¿Puedo usar un solo producto?">
    Sí. Cada producto funciona por separado. Podés empezar con una base de datos y sumar apps o buckets después.
  </AccordionItem>
  <AccordionItem title="¿Cómo funciona el CI/CD con GitHub?">
    Instalás la GitHub App de Olimpia, elegís repo y rama, y cada push se construye y se publica solo, sin cortes. Ver [Deploy desde GitHub](/apps/github).
  </AccordionItem>
  <AccordionItem title="¿Mis apps se conectan a la base por internet?">
    No. Usan la [red interna](/plataforma/red-interna). Las bases no aceptan conexiones de afuera hasta que habilitás el acceso externo.
  </AccordionItem>
  <AccordionItem title="¿Puedo tener backups en mi propia cuenta de AWS?">
    Sí. Configurás un bucket de AWS S3, Cloudflare R2, Backblaze B2, MinIO o cualquier S3 y elegís la frecuencia. Ver [Backups en tu S3](/postgres/backups).
  </AccordionItem>
  <AccordionItem title="¿Puedo usar mi dominio?">
    Sí, hasta 10 por app. Apuntás un CNAME a `domains.olimpia.cc`, cargás el TXT que prueba que el dominio es tuyo y el certificado se emite solo. Ver [Dominios](/apps/dominios).
  </AccordionItem>
  <AccordionItem title="¿Mi agente puede desplegar por mí?">
    Sí. Olimpia tiene un servidor MCP para Claude Code, Codex, Cursor y cualquier cliente MCP. Ver [Para agentes](/agentes).
  </AccordionItem>
  <AccordionItem title="¿Cuánto cuesta?">
    Hobby cuesta USD 5 por mes con USD 5 de uso incluido, y Pro, USD 20 con USD 20. Pagás por la memoria, la CPU y el disco que tus servicios usan de verdad, medidos por minuto. Durante el acceso anticipado no se pide tarjeta para empezar. Ver [Precios y facturación](/cuenta/facturacion).
  </AccordionItem>
  <AccordionItem title="¿Cuándo abre Olimpia?">
    Estamos sumando a los primeros equipos. Pedí acceso en [olimpia.dev](https://olimpia.dev) y te escribimos apenas haya lugar.
  </AccordionItem>
  <AccordionItem title="¿Puedo correr workers o tareas programadas?">
    Sí, un worker se despliega como cualquier app: el contenedor sigue corriendo aunque no atienda HTTP (su URL simplemente no va a responder). Las tareas programadas (cron) como recurso propio todavía no están disponibles; mientras tanto, programalas dentro de un worker.
  </AccordionItem>
  <AccordionItem title="¿Qué pasa con los archivos que mi app escribe en disco?">
    Se pierden en el próximo deploy. Guardá los datos en Postgres, Redis o un bucket.
  </AccordionItem>
</Accordion>

¿Te quedó otra duda? Escribinos a [hola@olimpia.dev](mailto:hola@olimpia.dev).
