Agora le da a cada agente de IA una computadora Linux real, con Chromium, apps y terminal, sin levantar un escritorio ni un navegador por agente. Documentación completa en [agora.olimpia.dev](https://agora.olimpia.dev).

## Qué hace

- **Agentes como cursores.** Cada agente tiene su propio puntero, teclado y pestañas sobre el mismo escritorio, con permisos que solo se reducen al delegar en subagentes.
- **Control del navegador por semántica o por píxeles.** Un snapshot compacto con referencias (`[e3] button "Sign in"`) para la web, y mouse y teclado reales para cualquier otra app.
- **Una persona cuando hace falta.** Ante un CAPTCHA o un login, el agente pide ayuda, vos tomás el control desde el visor y se lo devolvés sin perder la sesión.
- **Streaming liviano.** Video H.264 por WebRTC o WebSocket, y nada se captura ni se codifica si nadie está mirando.
- **Para tu agente.** Servidor MCP, API HTTP, dashboard web y plugin de Paseo.

Es open source (MIT o Apache-2.0): el código está en [github.com/olimpiacloud/agora](https://github.com/olimpiacloud/agora). Se instala en un servidor Ubuntu o Debian con:

```bash
curl -fsSL https://agora.olimpia.dev/install.sh | sh
```
