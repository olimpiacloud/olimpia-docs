Las réplicas de lectura van a copiar tu base Postgres en tiempo real para que puedas mandarles consultas de solo lectura: reportes, búsquedas y dashboards, sin cargar la base principal.

## Mientras tanto

Tu base [no tiene topes fijos de CPU ni memoria](/postgres): usa lo que necesita. Si tenés consultas pesadas, mirá las [consultas lentas en los logs](/postgres/logs-y-metricas) y agregá índices.
