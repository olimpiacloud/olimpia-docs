La CDN de Olimpia va a cachear en el edge los assets estáticos y las respuestas de tus apps, para servirlos desde el punto más cercano a cada usuario.

## Para qué

- Servir imágenes, JS y CSS sin que cada pedido llegue a tu app.
- Cachear respuestas de APIs públicas con las cabeceras `Cache-Control` de siempre.
- Bajar la latencia para usuarios fuera de Argentina.

## Mientras tanto

Todo el tráfico de tus apps ya entra por la red de Cloudflare, con HTTPS terminado en el borde. Para archivos estáticos, un [bucket público](/buckets/acceso-publico) sirve objetos desde almacenamiento global.
