The Olimpia CDN will cache static assets and app responses at the edge, so they are served from the location closest to each user.

## What it's for [#para-qué]

- Serve images, JS, and CSS without every request reaching your app.
- Cache public API responses using standard `Cache-Control` headers.
- Reduce latency for users outside Argentina.

## In the meantime [#mientras-tanto]

All traffic to your apps already goes through the Cloudflare network, with HTTPS terminated at the edge. For static files, a [public bucket](/buckets/acceso-publico) serves objects from global storage.
