Olimpia is designed to run in multiple regions. The first one is **BUE**, in [Buenos Aires](/plataforma/buenos-aires). We will announce new regions as they open.

When more regions open, you will choose the region for each project, and its apps and databases will stay together in that region. Within a region, each project is assigned to a server. See [Projects](/cuenta/proyectos#servidor).
