Olimpia is built to be run by people from the console **and** by agents from your editor or terminal. Connect Claude Code, Codex, Cursor, or any MCP client and ask it things like:

- "Deploy this folder to Olimpia."
- "Create a Postgres database for the `api` app and run the migrations."
- "Why did the last deploy of `web` fail? Fix it."
- "Point `app.miempresa.com` to the `web` app."

The agent follows the same rules and permissions as the console: it can't do anything you can't do, and it asks you to confirm before deleting anything.

## In three steps [#en-tres-pasos]

<Steps>
  <Step title="Connect the MCP server">
    ```bash
    claude mcp add --transport http olimpia https://api.olimpia.dev/mcp
    ```

    For other clients, see [Connect your agent](/agentes/conectar).
  </Step>
  <Step title="Authorize">
    The first time, olimpia.dev opens so you can approve the connection with your session. You never give your password to the agent.
  </Step>
  <Step title="Install the skill (optional)">
    ```bash
    bunx skills add olimpiacloud/olimpia-skills
    ```

    It teaches the agent the deploy flow, how to prepare each stack, and what to do when a build fails. See [Skill and plugin](/agentes/conectar#skill).
  </Step>
</Steps>

## What it can do [#qué-puede-hacer]

| To | Tools |
| --- | --- |
| Connect | `login` |
| Discover | `list_projects`, `get_project`, `get_app`, `get_usage` |
| Deploy | `create_app`, `get_upload_url`, `deploy`, `get_deployment`, `rollback`, `cancel_deployment` |
| Templates | `list_templates`, `deploy_template` |
| Configure | `update_app`, `get_env`, `set_env`, `create_project`, `create_environment` |
| Data | `create_resource`, `connect_resource`, `get_connection`, `set_public_access`, `list_tables`, `query_postgres` |
| Backups | `get_backups`, `set_backups`, `run_backup`, `disable_backups` |
| Domains | `add_domain`, `check_domain`, `remove_domain` |
| Observe | `get_logs`, `get_analytics`, `get_deployment` |
| Costs | `estimate_cost` |
| Delete | `delete_app`, `delete_resource`, `delete_environment` |

Full reference in [Tools](/agentes/herramientas).

## Server details [#datos-del-servidor]

| | |
| --- | --- |
| URL | `https://api.olimpia.dev/mcp` |
| Transport | Streamable HTTP, stateless |
| Authorization | OAuth 2.1 with PKCE, dynamic registration, and CIMD; or `Authorization: Bearer` with a personal token |
| Discovery | `/.well-known/oauth-protected-resource` and `/.well-known/oauth-authorization-server` |
