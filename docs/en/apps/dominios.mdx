## Your Olimpia subdomain [#tu-subdominio-de-olimpia]

Every app is available at `https://<subdominio>.olimpia.cc`, with HTTPS included. By default, the subdomain is the app name. You can change it in **Settings**.

:::warning
When you change the subdomain, the old address stops working immediately.
:::

If your app only uses custom domains, you can turn off the Olimpia subdomain in **Settings → Domains**: the app stops responding there, the subdomain stays reserved for you, and you can restore it at any time.

## Add a custom domain [#agregar-un-dominio-propio]

<Steps>
  <Step title="Add the domain">
    In **Settings → Domains**, click **Add domain** and enter the domain or subdomain, for example `app.tuempresa.com`.
  </Step>
  <Step title="Create the DNS records">
    The console shows the records to create with your DNS provider:

    | Type | Name | Value |
    | --- | --- | --- |
    | `CNAME` | `app` | `domains.olimpia.cc` |
    | `TXT` | `_olimpia.app` | (shown in the console) |

    The `_olimpia` `TXT` record is required: it proves the domain is yours. Until Olimpia sees it, it does not issue the certificate or send traffic to your app. Olimpia only needs to see it once.

    If you are migrating a domain that already has traffic, create that `TXT` record first. Once it is verified, the console may show another, optional `TXT` record that lets you validate the certificate before you point the `CNAME`.
  </Step>
  <Step title="Wait for verification">
    Olimpia checks DNS every 30 seconds, even if you close the page. Once it sees the `TXT` record and the `CNAME` points to the right place, it issues the HTTPS certificate. This usually takes a few minutes. The domain moves through **Waiting for DNS → Issuing certificate → Active**.
  </Step>
</Steps>

## Root domains [#dominios-raíz]

To use a root domain (`tuempresa.com`), your DNS provider must allow a `CNAME` at the root, using **CNAME flattening** or an **ALIAS** record. Cloudflare, DNSimple, and others support this. If your provider doesn't, use `www.tuempresa.com` and redirect the root domain to it.

## Rules [#reglas]

- Up to **10 domains** per app.
- A domain can't be used by two apps at the same time.
- A domain that isn't verified within **7 days** is removed automatically, so no one can reserve domains they don't own.
- If the app doesn't have a live deploy yet, the domain stays in **Waiting for first deploy**.

## Remove a domain [#quitar-un-dominio]

**Remove domain** stops serving the app on that domain immediately. You can add it again at any time. Remember to delete the DNS record too.
